Πολιτική απορρήτου

Μικρόφωνο

Η εφαρμογή ζητά πρόσβαση στο μικρόφωνο μόνο για να υπολογίσει την ένδειξη έντασης ήχου όσο η μέτρηση είναι ενεργή. Ο ήχος επεξεργάζεται προσωρινά στη συσκευή και δεν ηχογραφείται, δεν αποθηκεύεται και δεν αποστέλλεται πουθενά.

Δεδομένα που αποθηκεύονται

Το ιστορικό μετρήσεων (ώρα, διάρκεια, ελάχιστη/μέση/μέγιστη ένδειξη) αποθηκεύεται μόνο τοπικά στη συσκευή. Μπορείς να το διαγράψεις από την εφαρμογή ή απεγκαθιστώντας την.

Τι δεν συλλέγουμε

  • Δεν υπάρχουν λογαριασμοί χρηστών.
  • Δεν συλλέγουμε προσωπικά δεδομένα, τοποθεσία ή αναγνωριστικά συσκευής.
  • Δεν υπάρχουν διαφημίσεις ούτε εργαλεία ανάλυσης (analytics).

Σύνδεση στο internet

Η οθόνη «Σχετικά» φορτώνει από το GitHub Pages τη λίστα με τις άλλες εφαρμογές μας. Όπως κάθε ιστοσελίδα, ο διακομιστής του GitHub μπορεί να καταγράψει τεχνικά στοιχεία του αιτήματος (π.χ. διεύθυνση IP), σύμφωνα με τη δήλωση απορρήτου του GitHub.

Παιδιά

Η εφαρμογή δεν συλλέγει δεδομένα από κανέναν χρήστη, συμπεριλαμβανομένων των παιδιών.

Privacy policy

Microphone

The app asks for microphone access only to calculate the sound level reading while a measurement is running. Audio is processed temporarily on the device and is never recorded, stored or transmitted.

Data stored

Measurement history (time, duration, min/average/max reading) is stored only locally on the device. You can delete it in the app or by uninstalling it.

What we don't collect

  • There are no user accounts.
  • We don't collect personal data, location or device identifiers.
  • There are no ads and no analytics tools.

Internet connection

The About screen loads the list of our other apps from GitHub Pages. Like any web page, GitHub's server may log technical request details (e.g. IP address), as described in the GitHub Privacy Statement.

Children

The app does not collect data from any user, including children.
